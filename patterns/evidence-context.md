# Pattern — Evidence context

Claims and evidence should be separate objects.

A claim may change wording while the underlying evidence remains the same. Evidence may also become stale without invalidating the entire knowledge base.

## Minimum evidence record

- source;
- date;
- geography / population;
- claim supported;
- confidence / validation status;
- publication permission when relevant.

## Agent rule

A plausible statement is not evidence.

If evidence is missing, the agent should downgrade, qualify or remove the claim rather than invent support.

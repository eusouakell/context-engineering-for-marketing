# Pattern — Brand context

Brand context should constrain language and strategic meaning without becoming a dump of every brand artifact.

## Canonical inputs

- positioning;
- value proposition;
- message hierarchy;
- voice;
- terminology;
- claims policy;
- proof rules.

## Derived inputs

Use only when relevant:

- website copy;
- campaigns;
- decks;
- social posts.

Derived artifacts are examples, not authority.

## Failure modes

- outdated campaign copy overrides current positioning;
- tone examples are treated as factual evidence;
- a model "improves" an approved strategic statement;
- a channel artifact silently becomes canonical.

## Verification

Check:

1. positioning fit;
2. terminology;
3. unsupported claims;
4. voice;
5. evidence status.

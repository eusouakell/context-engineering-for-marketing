# Progressive disclosure

More context is not automatically better context.

Loading an entire knowledge base can increase:

- contradictions;
- stale-source exposure;
- token cost;
- attention dilution;
- accidental instruction conflicts.

A safer navigation pattern is:

```text
system entrypoint
→ target domain
→ canonical spec
→ required concepts
→ relevant decisions / evidence
→ task-specific reference
```

Expand only when the task requires it.

Stop when additional context no longer changes the decision criteria, factual basis or verification requirements.

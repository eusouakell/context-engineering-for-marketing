# Context is not a prompt

A prompt is an instruction presented to a model.

Context Engineering is broader: it designs the environment from which the model obtains the information and constraints needed to perform a task.

For marketing work, that environment may include:

- canonical brand knowledge;
- current market evidence;
- an audience model;
- task-specific references;
- tool outputs;
- retrieved documents;
- prior decisions;
- evaluation criteria;
- permissions and publication gates.

The practical distinction matters because many failures attributed to "bad prompting" are actually failures of context authority, selection, freshness or provenance.

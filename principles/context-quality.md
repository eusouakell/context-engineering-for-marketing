# Context quality

Evaluate context on six dimensions:

| Dimension | Question |
|---|---|
| Authority | Is this source allowed to define the fact or rule? |
| Relevance | Does it materially affect the task? |
| Freshness | Is it still valid? |
| Specificity | Does it meaningfully constrain execution? |
| Provenance | Can important claims be traced? |
| Cost | What is the token and cognitive cost of loading it? |

A useful working definition:

> High-quality context is the smallest set of authoritative information that materially improves task performance and can survive verification.
